# Findo Group — النسخة المحلية

نسخة مملوءة من واجهة findogroup.com، تعمل على Laravel 13 وPHP 8.4 مع PostgreSQL وRedis. الواجهة الأساسية تُرسل من Laravel/Blade كـHTML كامل، مع مكونات React 18 / JavaScript لتحريك الأجزاء الأصلية المعقدة وAlpine. لا توجد ملفات TypeScript في كود التطبيق الذي تم تسليمه.

## التشغيل على الجهاز الحالي

افتح `http://127.0.0.1:8080/`، أو شغّل ملف `Start-Findo-Local.command` الموجود بجوار مجلد المشروع داخل outputs.

من داخل المشروع:

```bash
./bin/start-local
./bin/stop-local         # إيقاف الويب وعامل النشر المجدول
./bin/stop-local --all   # إيقاف الويب وقاعدة البيانات وRedis الخاصة بهذه النسخة
./bin/backup-local      # نسخة PostgreSQL بصيغة pg_dump
```

المشروع موجود فعليًا على القرص `/Volumes/OS/CodexProjects/findo-group-20261002/app` بسبب امتلاء القرص الداخلي. رابط المجلد الموجود داخل outputs يشير إليه. يجب توصيل قرص OS حتى يعمل الموقع. بيانات PostgreSQL وRedis موجودة بجواره داخل `local-services`.

الخدمات مربوطة بـ127.0.0.1: الويب 8080، PostgreSQL 55439، Redis 56389. التشغيل العادي يستخدم ملفات JavaScript المبنية مسبقًا؛ لا يحتاج سيرفر Node يعمل في الخلفية. الخرائط وYouTube وروابط واتساب والمواقع الخارجية تحتاج الإنترنت.

## المحتوى المستعاد

- 775 رابط محتوى فعلي، بالإضافة إلى قالب 404 داخلي. 1,552 نسخة محتوى عربي/إنجليزي؛ المقالات تحتفظ بلغة النص الأصلية كما في الموقع.
- 665 مقالًا بنصوصها الكاملة، و8 تعليقات منشورة.
- 60 مشروعًا، و10 خدمات، و5 أنظمة، وصفحات الشركة والتدريب والأسعار والسياسات وصفحات الهبوط.
- 4,210 سجل مرفق من WordPress تمثل 4,202 مسار ملف أصلي فريد؛ جميع الملفات الأصلية موجودة.
- 23,755 ملفًا عامًا من uploads بحجم 1,353,890,789 بايت، يشمل الصور والمقاسات المشتقة وفيديوهات العملاء. أصول الواجهة الأصلية والخطوط وملف الشركة محفوظة أيضًا.
- عناوين SEO والوصف وcanonical وOpen Graph وTwitter وJSON-LD محفوظة من 751 صفحة منشورة، مع بيانات VideoObject الأصلية الموجودة داخل المحتوى.
- 1,363 تحويلًا تاريخيًا محفوظًا. المحتوى الحالي لصفحة `/portfolio` وملف الشركة PDF له أولوية على تحويلين قديمين للرئيسية. قواعد إضافية تغطي بدائل الخدمات القديمة وأرشيفات المدونة.

الروابط والبيانات داخل canonical وSchema تظل تشير إلى findogroup.com. النسخة المحلية ترسل noindex وتمنع الزحف عبر robots.txt. هذه حماية للمعاينة المحلية، ولا تعني أن الموقع المنشور تغير.

## تنظيم الكود

- `app/Http/Controllers/WebsiteController.php`: الصفحات، اللغة، التحويلات، وحالة 404.
- `app/Services/WebsiteContent.php`: قراءة المحتوى من PostgreSQL وتخزينه مؤقتًا.
- `resources/views/website/page.blade.php`: مستند HTML ومالك بيانات SEO.
- `resources/js/migrated`: المكونات الأصلية المستعادة، بعد إزالة TypeScript.
- `resources/js/islands.jsx`: تحميل التفاعلات حسب مكونات الصفحة؛ التنقل بين الصفحات يظل عبر Laravel.
- `resources/js/migrated/adapters`: اللغة والثيم وحفظ النماذج وقراءة المقالات محليًا.
- `app/Http/Controllers/LocalContentController.php`: البحث والفلاتر والتصفح من نسخة المحتوى المحلية.
- `storage/app/imports`: بيانات الاستعادة الفعلية، SEO، التعليقات، سجل الوسائط، والتحويلات.
- `public/wp-content/uploads`: الملفات العامة المستعادة بمساراتها الأصلية.
- `storage/backups`: النسخ الاحتياطية من PostgreSQL.

## لوحة التحكم

افتح `http://127.0.0.1:8080/admin`. زر تسجيل الدخول في واجهة الموقع يفتحها أيضًا. حساب المالك المحلي وبياناته محفوظان في ملف `Findo-Admin-Login.txt` بجوار رابط المشروع داخل outputs.

- المقالات: كتابة وتحرير ونشر ومسودات وجدولة بتوقيت القاهرة وأرشفة، مع تصنيفات وصور وSEO منفصل عن عنوان المقال.
- صفحات الموقع: النصوص والصور وروابطها وإخفاء الأقسام، وإضافة أقسام مخصصة وترتيبها. الأقسام الأصلية تحافظ على ترتيب تصميمها؛ مجموعات المحتوى والأقسام المخصصة تدعم الترتيب.
- إدارة المشاريع والخدمات والأنظمة والأسعار وآراء العملاء والشركاء والتدريب والفروع والقوائم والهيدر والفوتر.
- مكتبة الوسائط: رفع ملفات، تعديل النص البديل، وأرشفة واسترجاع دون كسر روابط الصور المنشورة.
- SEO: عناوين ووصف وcanonical وOpen Graph وSchema، تقارير النواقص والتكرار، خرائط الموقع، وتحويل 301 تلقائي عند تغيير الرابط.
- الطلبات والتعليقات والمستخدمون وصلاحيات المالك والمحرر ومسؤول SEO، وسجل تعديلات واسترجاع نسخ.

المحتوى محفوظ في PostgreSQL. عند التعديل يُعاد توليد HTML من المكونات الأصلية، وتُمرر نفس البيانات إلى React حتى تبقى النسختان متطابقتين. `bin/render-cms.cjs` يشغّل حزمة العرض الجاهزة في `storage/app/cms/renderer.cjs`. Node مطلوب وقت حفظ المحتوى الذي يحتاج إعادة عرض، وليس للبناء فقط؛ مساره قابل للتحديد عبر `FINDO_NODE_BIN`.

`bin/start-local` يشغّل عامل الجدولة تلقائيًا. `website:publish-due` يحدّث قوائم الموقع عند حلول موعد نشر مقال. لا تترك عامل جدولة إضافيًا يعمل على نفس النسخة.

## النماذج وحدود النسخة المحلية

نماذج التواصل والاستشارة وطلبات الخدمات والشراكات والوظائف والتدريب والنشرة والتعليقات تحفظ محليًا في `form_submissions`، بحالة `received_locally`. لا تُرسل بريدًا ولا تُنشئ حسابات حقيقية ولا تتصل بقاعدة بيانات الإنتاج. التعليقات الجديدة محفوظة للمراجعة ولا تظهر علنًا تلقائيًا. هناك طلبات اختبار واضحة بأسماء QA وبريد example.test من التحقق المحلي.

بوابة الطالب التعليمية ما زالت واجهة مستقلة عن إدارة الموقع. ربط حسابات الطلاب والدفع والرسائل الخارجية يحتاج مرحلة خاصة؛ حسابات لوحة التحكم الحالية مخصصة لإدارة الموقع التعريفي.

مكتبة التسويق تضم 12 بطاقة من المصدر الأصلي، لكن روابط ملفاتها `fileUrl` فارغة في المصدر المستعاد. محاولة قراءة قائمة Supabase العامة أعادت HTTP 522 أثناء التحقق؛ لذلك لا توجد ملفات PDF/Excel مختلقة مكانها. واجهة طلب القالب تحفظ الطلب محليًا، ويمكن الآن رفع الملف من مكتبة الوسائط وربطه بالبطاقة من لوحة التحكم.

ملفات إضافات WordPress المؤقتة، سجلاتها، النسخ الاحتياطية القديمة ومرفقات النماذج الخاصة ليست جزءًا من واجهة Laravel العامة. ما تم نقله منها أثناء الاستعادة محفوظ خارج public في أرشيف العمل المعزول.

## إعادة البناء والاستعادة

PHP 8.4، Composer، Node حديث، PostgreSQL 17، Redis. Node مطلوب للبناء وإعادة عرض صفحات CMS عند الحفظ.

```bash
composer install
npm ci
npm run build
php artisan migrate
php artisan website:import
php artisan website:sync-metadata
php artisan website:import-media
php artisan website:install-cms
php artisan website:sync-media-library
php artisan test
```

ملف `.env` الحالي مجهز لهذا الجهاز ويحتوي بيانات اتصال محلية خاصة. عند النقل لجهاز آخر، ابدأ من `.env.example`، جهز PostgreSQL وRedis، وأدخل بيانات الاتصال ثم نفّذ `php artisan key:generate`. انسخ مجلد `storage/app/imports` وملفات public مع الكود؛ مستودع الكود وحده لا يغني عن ملفات المحتوى.

يمكن استعادة ملف `.dump` إلى قاعدة بيانات PostgreSQL محلية جديدة بواسطة `pg_restore`، ثم تشغيل التطبيق على تلك القاعدة. لا تشغّل `migrate:fresh` على النسخة المملوءة.

الفحوص المؤكدة: بناء Vite، مجموعة اختبارات Laravel تشمل النشر والجدولة والصلاحيات والتعليقات والتحويلات وبيانات SEO، فحص HTTP لكل 776 مسارًا، مقارنة SEO لـ751 مسارًا، فحص جميع التحويلات التاريخية، اختبار عربي/إنجليزي، البحث والفلاتر، حاسبة الأسعار، قائمة الموبايل والثيم، حفظ نماذج محلية، وتشغيل فيديو عميل فعليًا. راجع تقرير التسليم وملفات CSV بجوار مجلد المشروع للأدلة والتفاصيل.

تم أيضًا اختبار نشر مقال من اللوحة وتغيير رابطه وأرشفته، وترتيب آراء العملاء واسترجاع نسختها السابقة، وعرض اللوحة على الموبايل. أدلة هذه المرحلة: `Findo-CMS-SEO-Verification.json` و`Findo-CMS-Route-Checks.csv` وصور لوحة التحكم داخل outputs. النشر الاختباري مؤرشف، والمقالات الأصلية المنشورة ما زالت 665.

مركز SEO يدعم فحص اللغتين وتنزيل JSON، ويميّز الأخطاء التقنية عن الملاحظات التحريرية. خريطة الموقع تستبعد المسودات والمجدول مستقبلًا وnoindex والصفحات التي تختار Canonical آخر. أمر `website:repair-legacy-links` يعرض إصلاحات الروابط الموروثة، ولا يحفظها إلا مع `--apply`؛ تُحفظ نسخ المحتوى قبل كل إصلاح.
